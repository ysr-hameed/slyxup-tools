# Slyxup Tools — 50-Tool SEO Research Roadmap (Rankable & Low-Competition)

> Last updated: 2026-08-13
> Mission: **build 50 tools that can actually rank**, focusing on low-competition, high-intent niches. Every tool is 100% client-side feasible.

## How to choose tools that RANK (research method)

Google ranks tools on **intent + authority + low competition**. These rules drove every pick below:

1. **Avoid saturated generic keywords** — `word counter`, `age calculator`, `JSON formatter`, `BMI`, `percentage calculator` are owned by calculator.net / wordcounter.net (huge domain authority). A new site cannot beat them. ❌ DROPPED.
2. **Niche down** — take a broad topic and add a qualifier: `fee calculator` → `tiktok shop fee calculator`. The narrower phrase has real searches but far fewer strong competitors. ✅ (Confirmed: TikTok Shop fee calc = "lowest-competition reseller platform".)
3. **Money-maker niches** = high intent = easier to rank *and* monetize (affiliate). Someone asking "how much do I keep" is ready to buy tools/subscriptions.
4. **Every tool = 1 long-tail guide** for topical authority + internal links.

### Feasibility (is it capable?)
- 100% browser JS (client component, no SSR/server).
- Static export compatible. No paid/external API. No heavy libs.
- Earnings/fee tools use **documented static 2026 assumptions**, adjustable inputs, Methodology + Sources (E-E-A-T). Never fake live data.
